# Portfolio Starter

A minimal, high-performance portfolio template built with Next.js 16, React 19, and Tailwind CSS.

## Features
- **Mouse Spotlight:** Radial mouse tracking light gradient (`components/spotlight.tsx`).
- **Dynamic Stack Grid:** 8-column tech stack with dynamic brand hover colors (`components/stack.tsx`).
- **Contribution Graph:** GitHub activity grid integration (`components/contribution-graph.tsx`).
- **Availability Badge:** Pulsing green live status pill.
- **Customizable Content:** Edit everything in a single file at `lib/content.ts`.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view your site.

## Customization

1. Edit your name, bio, projects, and social links in `lib/content.ts`.
2. Replace `public/avatar-placeholder.svg` with your own photo.
3. Update tech stack icons in `components/stack.tsx`.
